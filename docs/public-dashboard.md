# Публичный мониторинг (0.7.0)

- `/monitor` — новая страница обзора, только чтение, без авторизации.
- `/history`, `/history.json`, `/events.json` — просмотр истории без авторизации.
- `/settings`, `/settings.json`, `/settings/save`, `/settings/reset` — остаются под глобальной авторизацией ESPHome.
- `/` — штатная страница ESPHome, по-прежнему под паролем.
- Команды очистки истории отключены в публичном компоненте, чтобы нельзя было стирать данные без авторизации.

**Внимание:** `/logs.json` сейчас также доступен без пароля через публичный обработчик истории. Не записывайте пароли или токены в debug-логи. Для производственного использования потребуется выделить защищённый обработчик диагностики. Не публикуйте порт 80 в Интернет; предназначено для доверенной локальной сети.

## Windows

Из корня репозитория:

```powershell
git pull
.\scripts\build.ps1
.\scripts\flash-ota.ps1
```

Для USB-прошивки:

```powershell
.\scripts\flash-usb.ps1 -Port COM4
```

Порт замените на фактический. Если ESPHome CLI не установлен, используйте ESPHome Device Builder и пункт Install. Проект рассчитан на ESPHome 2026.7.3 / ESP-IDF 5.5.5, но сборка изменений не проверена на целевой плате.
